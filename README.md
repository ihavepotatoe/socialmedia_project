Social media project

## description

social media front end application built using javascript, html ,css, es6 modules and the noroff api

## features

register user
login user
view all posts
view specific post
create post
edit own post
delete own post
view profiles
view a users posts
follow and unfollow feature
search posts

## run the project locally

1 clone repository
2 open project folder
3 run

npx serve .
open from terminal

## api key

some features require a Noroff api key
open the browser console and add your own api key to local storage
localStorage.setItem("apiKey", "YOUR_API_KEY");
